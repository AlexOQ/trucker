The Recommendation Algorithm

The advisor scores every trailer by the best job one AI driver with it would find, and recommends five of the best for each city garage.

  1. Build depot cargo pools: Each depot in the city has a pool of cargo it can spawn, weighted by spawn probability (prob_coef). The simulation models 3 random jobs per depot on each visit.
  2. Eliminate dominated body types: If one trailer type can haul everything another can (and more), the weaker type is removed from consideration.
  3. Five of the best: AI drivers roll their own jobs instead of sharing one board, so a driver's earnings don't depend on what the others haul. The trailer with the highest expected value wins every slot; the runners-up are listed below it.
  4. Country-aware filtering: Trailers are filtered to those valid in the city's country. HCT and double trailers are only available in specific regions.

Understanding the Scores

City Score = 5 × the best trailer's expected value. That EV is an exact E[max of N] across all depots — the expected value of the best job a driver with that trailer would find. Higher score means more earning potential.

Trailer EV = expected earning value per job cycle for one driver on that trailer.
